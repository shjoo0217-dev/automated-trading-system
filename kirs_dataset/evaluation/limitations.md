# 알려진 한계와 제외 자료

- 표본은 티쓰리·JTC·레드캡투어의 6개 보고서에 한정된다. 한국IR협의회 전체 보고서 목록이나 시장 전체 모집단이 아니다. 원문 발간은 2023-11-17~2026-10-28이며 모두 2026-11-17 KST에 관측했다.
- KIRS 영문·기업·아웃소싱 목록과 w4 PDF 서버는 수집 시 503/상위 연결 실패. 외부 검색의 열람 시도에서도 timeout. 직접 목록이나 API 구조를 확보했다고 주장하지 않는다. 기업이 자체 IR에 올린 KIRS 보고서를 제한적으로 읽었다.
- Telegram Content Licensing 약관은 ML/AI 개발용 수집·색인·집계·사용을 금지한다. 조사 중 확인한 채널 본문·기업 수치를 결과물 및 학습 데이터에서 제외했다. 추가 스크래핑을 중단했다. 채널의 특정 링크 불일치는 접근조사 관찰일 뿐 이 데이터셋의 투자 신호로 쓰지 않는다.
- 539개 셀은 두 파서가 일치하고 산술 검사를 통과했지만 OpenDART 대조는 0개다. 두 파서 모두 같은 PDF 텍스트 레이어를 사용하므로 같은 잘못된 원문을 읽는 공통 오류 가능성이 있다. 3개 요약 페이지는 화면으로 표본 점검했지만 사람이 전체를 승인한 데이터는 아니다.
- 500개 셀의 표에서 연결/별도를 명시적으로 확인하지 못해 unknown. KTC 기술분석 39개 셀만 표의 K-IFRS 연결 표기를 사용한다. JTC 이외 연간 기간의 시작/종료일을 임의로 넣지 않았다.
- N/A와 흑전/적지 등 13개 비수치 셀은 null. 티쓰리 상장 전 PER/PBR/PSR의 원문 0.0 6개는 원자료에서 보존하며 특징에서 저평가 신호로 사용하지 않는다.
- 2023 레드캡투어 보고서의 EV/EBIDA 표기는 원문 row_label에 보존하고 정형 metric은 ev_ebitda로 통일했다. 지배주주순이익과 전체 순이익은 다른 metric이다. CAPEX는 현금유출 부호를 보존하며 양수 지출로 몰래 바꾸지 않는다.
- 보고서마다 주식 분할/소각/주당지표 기준이 다를 수 있다. 과거 EPS를 최근 보고서 숫자로 덮어쓰지 않는다. 수정·번역 쌍은 이번 표본에서 검증하지 못했으며 연결하지 않은 문서를 연결했다고 주장하지 않는다.
- 보고서 기준 시가총액/주식수는 반올림된 표기다. 한 시점 가격 29개 보조 항목은 일별 시세 이력도 거래소 라이선스도 아니다.
- 사업·위험 12개 태그는 짧은 근거 요약이다. 고객사/생산능력/시장점유율/주주 등 전체 문서의 모든 사실을 전수 구조화하지 않았다. 판독되지 않은 수치를 추정해서 추가하지 않았다.
- 행사 1건은 공개 KIND HTML의 일정만 확보했다. 해당 HTML에 발행 기업명이 없어 identity_status로 명시하고 종목 특징에 결합하지 않는다. 2025년 과거 행사이며 실제 영상 게시 여부는 미확인이다.
- 권한이 확인된 시세·상장폐지·거래정지·기업행동 자료가 없으므로 labels와 모델을 생성하지 않았다. 보고서가 발간된 기업, 기업 홈페이지에서 아직 내려받을 수 있는 보고서만 선택되는 편향이 크다. 이 수집 결과를 생존 종목 전체나 유망주 목록으로 해석할 수 없다.
- 실거래 백테스트 없음. 수수료·세금·슬리피지·유동성 가정을 적용한 수익률을 계산하지 않았다. 향후 이러한 비용, 거래대금 제한, 거래정지·상장폐지 처리와 권리조정 기준을 명시해야 한다.
- 신규 원문 대량처리 및 ML 학습 권한 미확보. 공개 열람 가능성/robots 허용은 저작권 이용허락이 아니다. 원문 PDF/전체 텍스트는 ZIP·GitHub·Drive에 배포하지 않는다.
- GitHub 스케줄은 지연/누락될 수 있고 사용자 계정의 무료 한도를 다른 작업과 공유한다. $0에서 가용성은 보장되지 않는다. Actions→Drive 지속 동기화는 별도 OAuth 없이는 실행되지 않는다. 현재 실제 배포와 실행 증거는 cloud/deployment_status.json을 따를 것.
