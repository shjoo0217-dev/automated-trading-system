# 데이터 품질 검사

검사 상태: **passed_with_limitations**. 스키마·셀 추출·산술·시점 규칙에 한정된 통과이며 공시 검증/권리 승인을 뜻하지 않는다.

| 항목 | 실제 결과 |
|---|---:|
| 기업 / 보고서 | 3 / 6 |
| 실적·재무 및 과거 지표 | 439행 |
| 전망치 및 전망 기반 지표 | 100행 |
| PDF 두 파서의 셀별 일치 | 539 / 539 |
| 추출 파서 불일치 검토 대기 | 0 |
| 비수치 표기 → null | 13 |
| 원문 0.0 배수 주의 표시 | 6 |
| 연결/별도 unknown | 500 |
| 연결 기준 명시 | 39 |
| OpenDART 대조 완료 | 0 |
| 특징 후보 / 학습 적격 | 6 / 0 |
| 예제 / 사람 승인 gold | 30 / 0 |
| 가격 정답 / 학습 모델 | 0 / 0 |

각 수치에 PDF의 SHA-256, 물리 페이지(1부터), 표명, 행명, 연도 열, 셀/라벨/기간 머리글 좌표가 있다. 누락·적지·흑전·N/A는 원래 토큰과 missing_reason을 보존한다. 원 단위 금액은 억원 × 100,000,000으로 분리 계산하고 퍼센트는 0~100 척도다.

실제로 확인한 레이아웃은 KIRS 기업리서치센터 5개 연도 요약표+재무 부록, 한국기술신용평가 3개 연도 요약표다. 미지원 레이아웃/스캔 PDF/열 개수 변화는 검토 대상으로 거절한다. OCR 또는 LLM 결과를 검증 없이 채택하는 경로는 없다. 수치 표본 화면 검사는 티쓰리 2026, JTC 2024, 레드캡투어 기술분석 2024의 물리 2페이지에서 수행했다.

자산=부채+자본은 억원 단위 개별 반올림을 고려해 2억원 허용, 영업이익률은 원자료 반올림 전파를 고려한 허용오차로 대조했다. 실제 실패 0건. 테스트 결과는 `test_results.txt`, 기계 판독 결과는 `quality_checks.json`에 저장한다.

발간일과 게시일 차이: 티쓰리 구 보고서 표지 2024-05-22, 기업 IR 게시 2024-06-14. 레드캡투어 아웃소싱 표지 2024-08-29, 첨부 표시 2024-08-30. 파일명/게시일 대신 표지 날짜를 발간일로 사용한다. 정확한 최초 공개시각은 모든 보고서에서 null이다.

JTC는 표에 2월 결산, 본문에 FY2024=2024년 3월~2025년 2월이 명시되어 있다. 같은 연도 숫자를 12월 결산 회사의 동일 달력기간으로 결합하지 않는다.

제외/보류: Telegram 본문, 실패한 KIRS 본사이트/영문 PDF, 차단된 KRX 상세, DART 인증 필요 자료, 불명확한 원문 전체 재배포, 미확인 목표주가/매매 의견. 실제 없는 자료의 빈 파일을 정상 데이터로 제공하지 않는다.
