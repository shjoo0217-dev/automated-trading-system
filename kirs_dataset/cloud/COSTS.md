# 비용 상한 US$0

**최종 상태: 사용자 요청에 따라 클라우드 반복 예약을 해제했습니다.** 다음 클라우드 예약은 없습니다. 아래 수치는 재활성화 시의 설계 추산입니다. Windows 실행에는 별도 클라우드 사용료가 없으며 기존 전기·인터넷 비용은 포함하지 않습니다.

사용자 조건: 월 추가 비용 상한 US$0. 사용자가 2026-11-17 KST에 GitHub 계정의 결제수단 미등록 상태를 확인했다. 외부 도구로 청구 설정을 직접 읽지는 못했다.

[GitHub 공식 Actions 과금 문서](https://docs.github.com/en/billing/concepts/product-billing/github-actions)를 실제 확인했다. 현재 문서는 GitHub Free의 월 포함 compute 사용량을 **US$12 상당**, artifact storage를 500MB로 안내한다. Linux 2-core 표준 runner의 현재 예시 단가는 $0.006/분이다. 과거 관행인 '항상 2,000분 고정'을 보편 규칙으로 쓰지 않고 플랜/현행 가격을 다시 확인해야 한다.

이 작업을 최대 10분으로 제한하면 31일 × 하루2회 + 주간최대5회 = 67회, 최대670분, 현행 표준 Linux 단가로 약 $4.02의 포함 compute를 소비한다. 초기 push/수동 재실행·임시 예약검증은 추가다. 다른 프로젝트와 계정 할당량을 공유하므로 실제 남은 무료 여유는 별도 확인해야 한다. 예상 **현금 청구는 $0**이며 무료 한도를 넘기면 작업이 중단되어야 한다.

실제 $0 방어 조건은 **결제수단 없음**이다. 문서상 결제수단이 없으면 포함 사용량을 소진한 뒤 실행이 차단된다. 예산 경보나 10분 timeout만으로 결제수단이 등록된 계정의 지출을 $0으로 하드 제한한다고 주장하지 않는다. 결제수단을 추가하면 workflow를 먼저 비활성화하고 유료 사용 차단 설정을 별도로 검증한다. Larger runner, 유료 self-hosted 서비스, GPU, 유료 API, 유료 Google Cloud 리소스, 유료 저장소 증설은 사용하지 않는다.

GitHub Actions artifact 업로드와 캐시를 사용하지 않는다. 버전 ZIP은 비공개 Git 브랜치에 보존하며 논리 아카이브 한도 100MB에서 새 발행을 멈춘다. Git 커밋 이력 전체 용량을 자동 제한하는 의미는 아니다. Google Drive는 연결된 계정의 기존 저장공간을 사용하며 공간 부족 시 업로드 실패를 보고하고 자동 유료 업그레이드하지 않는다. Drive의 남은 용량은 이 도구로 확인하지 못했다.

중지는 OPERATIONS.md의 Disable workflow + 진행 중 run Cancel. 비용 조건을 확인할 수 없게 되면 운영을 중지한다. 무료 서비스의 정책 변경으로 계속 실행되는 것을 보장하지 않는다.
