# 학습·평가 실행 상태

실제 모델 학습: 미실행. 실제 성과 평가: 미실행. 성과 수치: 없음(null).

보고서 추천·목표주가·상승여력을 정답으로 사용하지 않습니다. 가격, 거래량, 거래일 달력,
배당/분할과 상장폐지 정산, 비교 지수의 허가된 데이터가 없고, 모델 학습 이용허가도 없습니다.
예스티 감사 레코드는 목표주가 충돌로 제외됩니다. 1건으로 학습 숫자를 만들지 않습니다.

`pipeline/star_pipeline/train.py`는 Ridge와 과거 평균/0 초과수익 기준모델을 구현합니다.
표본 100건, 종목 20개, purge 후 train 40/validation 20/test 20은 운용 전 최소 차단 기준일 뿐
통계적 충분성을 보장하지 않습니다. 시점 경계는 데이터 확보 후 사전에 고정합니다.
동일 문서·수정본·같은 파일 해시의 연결 그룹이 여러 분할에 걸치면 전체 그룹을 제외하고,
라벨 기간이 다음 분할 시작일에 닿는 앞 구간 표본도 제외합니다.

입력 전처리는 train에서만 fit합니다. alpha 1/10/100은 validation으로 선택하고 test는 최종 1회 평가합니다.
초기 비용 가정은 왕복 30bp이며, 실제 증권사 수수료·시장별 세금·슬리피지로 교체해야 합니다.
출력 selected_mean_net_excess는 보고서별 진단치입니다. 중복 보유기간을 가진 보고서들을 독립 투자로
취급해 CAGR·Sharpe·실전 수익률을 계산하지 않습니다. 포트폴리오 백테스트·체결·시장충격 검증은 미구현입니다.

라벨 정의: 가용시점 이후 진입 거래일 t의 수정 시가, t를 포함한 20번째 거래일(t+19)의 수정 종가.
진입점에 고정한 전방 총수익 조정으로 배당·분할을 반영한 주식 수익률에서 동일 기간 지수 수익률을 뺍니다.
KOSPI/KOSDAQ 총수익지수를 종목 시장에 따라 사전에 선택합니다. 종목/지수 조정 정의가 다르면 거부합니다.
거래정지·상장폐지 정산 누락·거래일 누락은 0수익 처리하지 않고 별도 제외·누락 사유로 기록합니다.
해당 기업을 전체 표본 명부에서 삭제하지 않아 생존편향을 점검할 수 있게 합니다.

가격 공급자 실제 연동, 역사적 종목 마스터, 전체 상장폐지 포함 정도, 원문 수정 이력의 과거 공개 증거는 미확보입니다.
